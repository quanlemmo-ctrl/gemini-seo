# Astro Affiliate Template (SEO & Conversion Engineered)

High-converting, ultra-fast affiliate marketing website template built on **Astro 5** and **Tailwind CSS**.
Engineered specifically for **Product Reviews, Buyer's Guides, and Coupon/Promo Code Portals**.

## Key Features

- ⚡ **100/100 Core Web Vitals**: Zero JavaScript by default, instant page transitions.
- 🛍️ **High-CTR Affiliate Components**:
  - `CouponCard.astro`: Click-to-copy discount code + auto opens merchant URL in a new tab.
  - `ReviewBox.astro`: Wirecutter-style score, Quick Verdict (optimized for AI Overviews), key pros/cons.
  - `ComparisonTable.astro`: Multi-product comparison matrix with sticky header on scroll.
  - `ProsCons.astro`: Visual 2-column pros and cons list.
  - `AffiliateButton.astro`: Trackable CTA button with `rel="sponsored nofollow"`.
  - `AuthorCard.astro`: E-E-A-T credentials with Fact-Checked badge.
  - `FaqAccordion.astro`: Interactive questions with automated `FAQPage` JSON-LD schema.
  - `TableOfContents.astro`: Auto-generated table of contents.
- 🔒 **Link Cloaking**: Safe internal redirects via `/go/[slug]` with `noindex, nofollow` protection.
- 🤖 **GEO & AI Search Ready**: Robots.txt and markup optimized for Google AI Overviews, Perplexity, and ClaudeBot.

## Getting Started

```bash
npm install
npm run dev
npm run build
```
